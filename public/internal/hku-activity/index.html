02 / Read with careWhat this report can say

The official staff directories define the roster, including academic, honorary, adjunct and non-academic entries. Current directory membership is not proof of someone’s affiliation on an earlier event date.

Public records are tentative until reviewed. A named mention establishes a connection to a source, not sole authorship, project completion or a verified award. Scheduled exhibitions and workshops remain announcements, even after their advertised dates.

This first pass checks a bounded set of HKU sources and staff profiles. It is not an exhaustive search of journals, studios, publishers or the wider web. Undated and year-only material is not silently assigned to this month.

The page is unlisted and requests no indexing. It is not password-protected, and its data contains only public professional information.
